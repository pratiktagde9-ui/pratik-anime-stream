PRATIK ANIME STREAM — UI TEMPLATE
==================================

Yeh ek frontend template hai — same dark theme, red accents,
search bar, featured category cards, watch history rail,
newest drops rail, aur bottom navigation (Movies / Series /
Home / Anime / Cartoon) jaisa aapke screenshot mein tha.

IMPORTANT:
- Isme koi bhi copyrighted anime/cartoon (Dragon Ball, Pokemon,
  Shinchan, Transformers, etc.) ka naam ya artwork nahi hai.
- Sab jagah placeholder titles aur emoji icons use kiye gaye
  hain jinhe aap data.js file mein apne khud ke / licensed
  content se replace kar sakte hain.

FILES:
- index.html   -> page structure
- style.css    -> saara styling (colors, layout, fonts)
- data.js      -> placeholder content (yahan apna data daalein)
- app.js       -> UI ko data se render karta hai

KAISE USE KAREIN:
1. Zip extract karein.
2. index.html ko browser mein kholein — turant preview dikhega.
3. data.js mein apne titles/categories daalein.
4. style.css mein colors/fonts customize karein agar chahiye.
5. Real content ke liye aapko apna khud ka video hosting /
   licensed streaming backend jodna hoga — yeh sirf UI hai.

Agar aap isko real backend se jodna chahte hain (apna
original content ya properly licensed content ke sath),
bata dijiyega — us part mein bhi madad kar sakta hoon.
